verify

Optional: after a removal, every remaining mention of the removed names.

Get Prism See the benchmarks

Measured against native Claude Code.

Prism 1.0 (measured on v0.87.39) against Claude Code's own tools, Sonnet 5.5, on two task sets: 32 change tasks and 40 real bug-fix issues. The tasks, run records, transcripts, and limits are public.

Change work: 0.76× cost

32 renames and signature changes in Python, Java, TypeScript and Go. Prism solved all 32 (native 31) with 0.65× the tool calls. About 22% cheaper over a working session.

Bug fixes: 0.92× cost

40 GitHub issues filed after the model's training cutoff. Same results as native (25 vs 23 solved, within noise) with 0.85× the tool calls. About 8% cheaper over a session.
